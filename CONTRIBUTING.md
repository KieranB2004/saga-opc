# Contributing to SAGA-OPC Project

## Code of Conduct

Please be respectful and professional in all interactions. This is an academic research project.

## How to Contribute

### Reporting Bugs

If you find a bug:
1. Check existing issues first (GitHub Issues)
2. Provide steps to reproduce the bug
3. Include expected vs actual behavior  
4. Mention Python version and environment details

### Suggesting Features

Propose new features with:
- Clear description of intended functionality
- Use case or research motivation
- Rough design approach if known

### Pull Request Process

1. Fork and clone repository
2. Create feature branch from main
3. Implement changes following existing patterns
4. Write tests for new functionality
5. Update documentation as needed  
6. Ensure all tests pass
7. Submit pull request with description

### Code Style Guidelines

- Use Python 3.9+ syntax
- Follow PEP 8 style conventions  
- Add docstrings to public functions/classes
- Type hint function signatures where appropriate
- Keep functions focused on single responsibility
- Comment complex logic, not trivial operations

## Academic Integrity Notice

This project uses AI assistance for scaffolding per policy. All contributions must:
- Include AI usage disclosures at top of files if applicable  
- Have implementations independently verified by contributor
- Follow existing documentation patterns

See `AI_USAGE.md` for detailed disclosure requirements.
